# SonoRiva 1.16.0

Date de publication : 1er septembre 2026.

## Forfait de démonstration

La démonstration publique utilise un forfait interne distinct de l’offre gratuite permanente et des abonnements. Ce forfait est visible dans l’administration, mais il ne peut pas être attribué à un compte client, publié dans le catalogue tarifaire, synchronisé avec Stripe ou supprimé.

L’éditeur configure le quota de stockage, la durée d’inactivité avant réinitialisation, le nombre maximal de fichiers importés et la taille maximale d’un fichier. Il contrôle également la modification et l’enregistrement des dispositions, les playlists, la télécommande et le nombre maximal de spectacles.

## Valeurs initiales

La migration crée le forfait avec les capacités appliquées jusque-là par le code :

- 24 heures d’inactivité avant expiration ;
- 15 fichiers importés au maximum ;
- 5 Mo maximum par fichier ;
- 80 Mo de stockage ;
- un spectacle ;
- dispositions personnalisées, playlists et télécommande disponibles.

Les comptes de démonstration existants sont rattachés à ce forfait. Les nouvelles limites sont affichées sur l’écran de connexion, dans le bandeau de démonstration et dans les paramètres du compte.
