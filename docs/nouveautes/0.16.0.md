# CueForge 0.16.0

Date de publication : 29 août 2026.

## CueForge Bridge

CueForge Bridge est un moteur audio macOS facultatif. Le réglage **Paramètres → Moteur et sorties audio** permet de conserver le moteur **Navigateur · Web Audio** ou de sélectionner **CueForge Bridge** après association.

L’association utilise un ticket valable cinq minutes et utilisable une seule fois. Le bouton **Connecter le bridge** ouvre l’URL native `cueforge-bridge://pair`. Le bridge échange le ticket avec CueForge, conserve son jeton d’appareil dans le trousseau macOS et ouvre son serveur local sur `127.0.0.1:43821`.

## Lecture et stockage

Le bridge télécharge les fichiers audio compressés depuis le compte CueForge et les conserve dans son propre cache. La commande **Synchroniser le spectacle** prépare tous les fichiers du spectacle sélectionné. Une lecture dont le fichier n’est pas encore présent déclenche son téléchargement avant le démarrage.

Le moteur natif prend en charge les lectures simultanées, les points de début et de fin, les fondus, le volume, la pause, la boucle, le déplacement dans le morceau et les arrêts.

## Sorties

Les paramètres du bridge exposent deux sélections indépendantes : **Régie principale** et **Préécoute**. Chaque sélection contient la sortie système et les périphériques audio rendus disponibles par macOS.

## Mode navigateur

Le moteur Navigateur reste le mode par défaut. Les pads, playlists, préécoutes, fondus, raccourcis, télécommande et fonctions hors ligne restent disponibles sans installation ni association du bridge.
