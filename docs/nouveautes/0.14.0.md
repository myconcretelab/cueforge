# SonoRiva 0.14.0

Date de publication : 28 août 2026.

## Forfait gratuit

Un forfait est traité comme gratuit lorsqu’au moins un prix est renseigné et que tous ses prix renseignés valent `0 €`. Un prix laissé vide rend la périodicité correspondante indisponible.

Lors de l’inscription sur un forfait gratuit :

- le compte et son premier spectacle sont créés immédiatement ;
- l’accès est actif sans période d’essai ;
- le quota de stockage défini sur le forfait s’applique ;
- aucun client, abonnement ou moyen de paiement Stripe n’est créé.

## Passage vers un forfait payant

Le propriétaire du compte peut sélectionner une offre payante depuis **Paramètres → Offre et stockage**. Le bouton **Continuer avec Stripe** ouvre alors Checkout avec la périodicité choisie, la durée d’essai du forfait et la collecte du moyen de paiement.

Un compte sans abonnement Stripe peut aussi activer un forfait gratuit public depuis cette rubrique. Un compte possédant déjà un abonnement Stripe continue d’utiliser le portail de facturation.
