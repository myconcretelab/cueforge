## Migration dans le navigateur

Au chargement, l’application copie les valeurs des anciennes clés de stockage vers les clés `cueforge-*` ou `cueforge:*`, puis supprime les anciennes clés.

Le service worker copie les réponses du cache audio historique vers `cueforge-audio-v1`. L’ancien cache est supprimé après la copie.

Le serveur accepte l’ancien cookie de session, crée le cookie `cueforge_session` avec le même jeton, puis efface l’ancien cookie.

## Changement de domaine

Les données de navigateur sont isolées par origine. Le nouveau domaine peut donc nécessiter une nouvelle connexion et une nouvelle mise en cache hors ligne.

L’ancienne adresse reste temporairement déclarée comme origine autorisée. Les comptes, spectacles, catégories, playlists et fichiers audio utilisent la même infrastructure et le même format de données.
