# CueForge 0.4.0

<p class="release-lede">25 août 2026 · CueForge entre en scène</p>

La régie adopte une nouvelle identité : **CueForge**, avec la signature **Play sound. Play the scene.** Le nom évoque à la fois le déclenchement précis d’un son et la fabrication patiente d’un spectacle.

## Une identité cohérente

- Le nom CueForge et le monogramme **CF** apparaissent dans l’application, la PWA et la documentation.
- L’application est accessible sur `cueforge.sebastienj.com`.
- La documentation et le dépôt Community utilisent les mêmes nom et adresse.

## Une transition sans perte

Sur l’ancienne adresse, CueForge reprend automatiquement les préférences enregistrées, les projets récemment consultés et les sons rendus disponibles hors ligne. Les sessions existantes restent reconnues pendant la transition.

L’adresse historique reste provisoirement active afin de laisser le temps de mettre à jour les favoris et les installations PWA. Une connexion sur la nouvelle adresse peut être nécessaire, car les navigateurs isolent les données de chaque domaine.

## Aucun changement dans vos spectacles

Les comptes, projets, catégories, playlists et fichiers audio restent sur la même infrastructure. Cette version change l’identité et les points d’accès, sans modifier le format des données métier.
