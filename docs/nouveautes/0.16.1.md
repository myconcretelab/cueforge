# SonoRiva 0.16.1

Date de publication : 29 août 2026.

## Téléchargement du bridge

La rubrique **Paramètres → Moteur et sorties audio** contient un lien vers la publication GitHub de SonoRiva Bridge.

La publication contient deux images disque : `aarch64` pour les Mac Apple Silicon et `x64` pour les Mac Intel. Les deux versions fournissent le même moteur audio, le même cache et les mêmes commandes locales.

Les paquets utilisent une signature ad hoc. Ils ne possèdent pas de certificat Apple Developer et ne sont pas notariés. macOS peut afficher un blocage lors de la première ouverture ; l’autorisation correspondante se trouve dans **Réglages Système → Confidentialité et sécurité**.
