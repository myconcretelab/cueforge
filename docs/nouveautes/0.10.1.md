# CueForge 0.10.1

Date de publication : 25 août 2026.

## Messages de version

Dans un espace de démonstration, les éléments suivants ne sont pas affichés :

- la bannière indiquant qu’une mise à jour est prête ;
- l’ouverture automatique de la fenêtre **Nouveautés** ;
- la rubrique **Nouveautés** des paramètres.

Ces trois éléments restent disponibles dans les espaces personnels.
