# CueForge 0.3.0

<p class="release-lede">25 août 2026 · La documentation entre en scène</p>

CueForge possède désormais son propre centre d’aide public. Il accompagne les nouveaux utilisateurs, documente les fonctions essentielles de la régie et fournit un point d’entrée clair lorsqu’un problème survient.

## Un guide accessible partout

- La documentation est disponible sans compte à l’adresse `/docs/`.
- Une recherche locale retrouve instantanément une commande ou un terme.
- La navigation sépare les premiers pas, les guides pratiques, la référence et le dépannage.
- Le design reprend l’identité sombre et orange de CueForge.

## Depuis l’application

Une section **Aide et documentation** apparaît dans les paramètres. Les fenêtres de nouveautés proposent également un accès direct à la note détaillée de la version installée.

## Pour CueForge Community

Le centre d’aide comprend les prérequis et la procédure d’installation de la version auto-hébergée. Les sources Markdown vivent dans le même dépôt Git que l’application : une correction documentaire peut donc être relue et publiée avec le code concerné.

## Publication contrôlée

Le build de production compile désormais le client, la documentation et le serveur. Le contrôle de version refuse une publication si la note détaillée correspondant au numéro de version est absente.
