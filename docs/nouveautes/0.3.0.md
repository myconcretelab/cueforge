# SonoRiva 0.3.0

<p class="release-lede">25 août 2026 · Documentation intégrée</p>

## Documentation publique

- publication sous `/docs/` sans authentification ;
- recherche locale dans le contenu ;
- rubriques de fonctionnement, guides, référence, dépannage et versions ;
- liens vers l’application et le dépôt Community.

## Intégration dans l’application

La section **Aide et documentation** des paramètres ouvre la documentation. Les notes de version contiennent un lien vers leur page détaillée.

## Construction

Les sources sont des fichiers Markdown stockés dans le dépôt. Le build VitePress produit la documentation dans `dist/client/docs`, puis le serveur la publie avec le client.

Le contrôle de publication vérifie l’existence d’une page correspondant au numéro de version.
