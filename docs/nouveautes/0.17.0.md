# SonoRiva 0.17.0

Date de publication : 29 août 2026.

## Bridge Windows

SonoRiva Bridge est disponible pour Windows x64 au moyen d’un installateur NSIS. Il fournit le même cache audio natif, la même sélection indépendante des sorties principale et préécoute et les mêmes commandes de lecture que les versions macOS.

L’association s’effectue depuis **Paramètres → Moteur et sorties audio** avec le bouton **Connecter le bridge**. Le lien `sonoriva-bridge://` ouvre l’application Windows ou réutilise son instance déjà active, puis lui transmet un ticket temporaire à usage unique. Les clés permanentes sont conservées dans le Gestionnaire d’identification Windows.

La publication SonoRiva Bridge 0.2.0 contient l’installateur Windows x64 ainsi que les images disque pour Mac Apple Silicon et Mac Intel. L’installateur Windows n’est pas signé et peut déclencher un avertissement SmartScreen.

Le moteur **Navigateur · Web Audio** reste le moteur par défaut. Toutes les fonctions de SonoRiva restent disponibles sans installer ou sélectionner le bridge.
