# SonoRiva 1.0.0

Date de publication : 29 août 2026.

## Identité

L’application, l’administration, la documentation, les e-mails transactionnels et le site public utilisent le nom **SonoRiva**, le monogramme **SR** et une palette sombre à accent aqua.

Les métadonnées PWA, les caches hors ligne, les clés du stockage local et le cookie de session utilisent le préfixe `sonoriva`.

## Adresses

Le site public est disponible sur `https://sonoriva.fr`. L’application, l’administration, l’API et la documentation sont disponibles sur `https://app.sonoriva.fr`.

## SonoRiva Bridge

SonoRiva Bridge 1.0.0 utilise le protocole `sonoriva-bridge://`, l’identifiant système `fr.sonoriva.bridge` et des espaces de configuration, de cache et de trousseau propres à SonoRiva.

Les paquets de bureau sont publiés dans le dépôt GitHub `myconcretelab/sonoriva` sous le nom `SonoRiva-Bridge`.

## Rupture de compatibilité

Les préférences, caches, sessions, associations et installations liés aux identités antérieures ne sont pas repris par cette version.
