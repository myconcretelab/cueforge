# CueForge 0.5.0

<p class="release-lede">25 août 2026 · Administration commerciale</p>

## Tableau de bord

L’adresse `/admin` contient quatre vues : vue d’ensemble, comptes, forfaits et utilisateurs. L’accès en consultation nécessite le rôle `admin` ou `super_admin`. Les modifications nécessitent le rôle `super_admin`.

## Comptes et accès

Chaque compte utilise un forfait et un état d’accès. Le forfait fournit le quota de stockage et la durée d’essai. Un quota exceptionnel peut être défini sur un compte.

Les écritures sont disponibles pour les états `trialing`, `active` et `grace_period`. Elles sont refusées pour les états `read_only` et `suspended`.

## Forfaits et abonnements

Le catalogue de forfaits contient les prix mensuel et annuel, le quota, la durée d’essai et le forfait attribué par défaut. Le modèle d’abonnement conserve les identifiants et périodes d’un futur prestataire de paiement sans dépendre d’une API particulière.

## Administration

Les rôles de plateforme sont stockés séparément des rôles internes aux comptes. Les changements de compte, de forfait et d’utilisateur sont enregistrés dans le journal d’audit.
