# SonoRiva 1.13.0

Date de publication : 1er septembre 2026.

## Dispositions nommées

Le choix 6/8/12 disparaît de l’éditeur : la grille interne utilise désormais douze colonnes. Les dispositions enregistrées auparavant avec une autre résolution sont converties automatiquement.

Le bouton **Enregistrer** sauvegarde la disposition actuelle sous un nom personnalisé. Elle apparaît ensuite dans **Mes dispositions**, sous les modèles fournis par SonoRiva. Une disposition enregistrée peut être chargée ou supprimée dans l’éditeur. Les configurations sont conservées localement pour chaque utilisateur.

## Catégories et recherche

Les cartes de catégories restent carrées lorsque la hauteur du bloc change. Les commandes de réorganisation et d’ajout sont placées immédiatement à droite du titre **Catégories**.

Les modes de recherche **Noms** et **Tags** utilisent un switch segmenté. La commande Freesound et le rappel du raccourci clavier sont séparés visuellement.
