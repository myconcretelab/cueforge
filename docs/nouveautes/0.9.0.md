# CueForge 0.9.0

Date de publication : 25 août 2026.

## Réglages des forfaits

Le formulaire d’un forfait contient les champs suivants :

- **Visible sur le site** ;
- **Mis en avant** ;
- **Ordre d’affichage**.

Un forfait mis en avant doit être visible. La sélection d’un nouveau forfait mis en avant retire cet état au forfait précédent.

## API publique

La route `GET /api/public/plans` ne nécessite pas de session. Elle retourne uniquement les forfaits actifs dont le réglage **Visible sur le site** est activé.

La réponse utilise un cache HTTP et ne contient aucune donnée de compte ou d’utilisateur.

## Bloc WordPress

Le bloc **Forfaits CueForge** récupère l’API depuis le serveur WordPress. La réponse est conservée pendant cinq minutes. Après une réponse valide, une copie persistante est enregistrée et utilisée si l’API devient indisponible.

La page d’accueil utilise ce bloc dans la section **Offres**. Les cartes affichent le nom, la description, les prix, le quota, la durée d’essai et l’état de mise en avant.
