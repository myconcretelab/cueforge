# CueForge 0.15.0

Date de publication : 28 août 2026.

## Sortie audio

La rubrique **Paramètres → Sortie audio** affiche la sortie système et les périphériques de lecture rendus accessibles par le navigateur.

Le périphérique sélectionné reçoit :

- les lectures lancées depuis les pads et les playlists ;
- la préécoute de l’éditeur de piste ;
- la préécoute des résultats Freesound.

Le choix est enregistré dans le stockage local du navigateur sur l’appareil utilisé. Si la sortie enregistrée ne peut plus être appliquée, CueForge revient à la sortie système.

## Disponibilité

Le réglage est affiché lorsque le navigateur prend en charge la sélection de sortie d’un contexte Web Audio. Un bouton **Choisir** ouvre aussi le sélecteur natif lorsque cette fonction est disponible dans le navigateur.

Lorsque l’API de sélection n’est pas disponible, CueForge continue d’utiliser la sortie audio définie par le système.
