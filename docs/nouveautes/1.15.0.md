# SonoRiva 1.15.0

Date de publication : 1er septembre 2026.

## Fonctionnalités définies par forfait

Chaque forfait contient trois droits indépendants : modification et enregistrement des dispositions, playlists et télécommande. L’administration active ou désactive chaque droit dans l’éditeur du forfait.

Le forfait définit également un nombre maximal de spectacles. Une valeur vide correspond à un nombre illimité. Lorsque la limite est atteinte, la création d’un nouveau spectacle est refusée.

## Changement de forfait

Le retrait d’un droit ne supprime pas les spectacles, playlists ou dispositions déjà enregistrés. Ils redeviennent accessibles si le compte reçoit ensuite un forfait qui inclut la fonctionnalité correspondante.

Les forfaits créés avant cette version conservent les trois fonctionnalités et un nombre illimité de spectacles.
