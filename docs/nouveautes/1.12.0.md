# SonoRiva 1.12.0

Date de publication : 1er septembre 2026.

## Modules repliables

La Playlist et les Actions de déclenchement peuvent être réduites depuis une commande de 19 pixels placée dans leur angle supérieur droit. Le mécanisme est commun aux deux modules et peut accueillir d’autres panneaux.

Un module réduit devient une barre de 34 pixels contenant une icône et son titre. La barre de la playlist affiche également son nombre de morceaux. Un clic sur cette barre restaure le contenu du module.

## Playlist

La playlist compacte et les autres dispositions partagent désormais le même état replié. L’ajout d’une catégorie, le chargement d’une playlist ou le dépôt d’un morceau ouvre automatiquement une playlist réduite.

L’état ouvert ou replié de chaque module est conservé dans la disposition locale de l’utilisateur. Sur mobile, la barre réduite reste disponible dans le flux vertical.
