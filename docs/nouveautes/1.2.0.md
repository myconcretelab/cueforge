# SonoRiva 1.2.0

Date de publication : 31 août 2026.

## Sélection multiple

Le tableau de bord contient un mode de sélection multiple. Les morceaux peuvent être ajoutés ou retirés de la sélection par clic ou toucher. À la souris, un rectangle sélectionne toutes les cartes qu’il touche. Les touches Maj, Ctrl et Cmd permettent d’ajouter un nouveau rectangle à la sélection existante.

Une barre contextuelle affiche le nombre de morceaux sélectionnés et fournit les commandes **Tout sélectionner**, **Effacer** et **Modifier**.

## Édition de lot

L’édition de lot peut modifier la catégorie, la couleur, les tags, le volume, la lecture en boucle et les fondus d’entrée ou de sortie. Seuls les champs cochés sont envoyés et appliqués.

Les tags disposent des opérations **Ajouter**, **Retirer** et **Remplacer**. Le remplacement par une liste vide supprime tous les tags des morceaux sélectionnés.
