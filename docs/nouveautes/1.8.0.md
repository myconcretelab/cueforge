# SonoRiva 1.8.0

Date de publication : 31 août 2026.

## Import de dossiers

Un dossier déposé sur l’application est lu récursivement. Lorsque des morceaux se trouvent dans des sous-dossiers, SonoRiva demande comment reproduire cette organisation avant de commencer le transfert.

Trois modes sont disponibles : une catégorie par dossier de premier niveau, une sous-catégorie par dossier de premier niveau dans la destination active, ou tous les noms de dossiers du chemin comme tags du morceau.

Une catégorie ou sous-catégorie existante portant le même nom est réutilisée. Les morceaux placés directement à la racine restent dans la catégorie active ou sans catégorie depuis la vue globale.
