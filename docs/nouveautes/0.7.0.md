# CueForge 0.7.0

Date de publication : 25 août 2026.

## Réinitialisation du mot de passe

La page de connexion contient le lien **Mot de passe oublié ?**. Le formulaire accepte l’adresse e-mail du compte et affiche une réponse identique que le compte existe ou non.

Le message contient une adresse vers `/reset-password`. Le lien expire après 30 minutes et ne peut être utilisé qu’une fois.

Après validation du nouveau mot de passe :

- le mot de passe précédent n’est plus accepté ;
- le jeton de réinitialisation est invalidé ;
- les autres jetons encore ouverts pour le compte sont invalidés ;
- toutes les sessions du compte sont supprimées.
