# S1 0.2.0

<p class="release-lede">25 août 2026 · Des mises à jour plus sereines</p>

Cette version installe le premier workflow de publication de Standby One. Les nouveautés sont visibles dans l’application et une mise à jour ne peut plus interrompre une lecture en cours.

## Nouveautés

- Une fenêtre présente les changements importants après la connexion.
- Un badge signale les notes de version qui n’ont pas encore été consultées.
- Les notes restent accessibles depuis les paramètres.
- La version installée est affichée dans la barre d’état.
- Une nouvelle PWA attend une confirmation explicite avant de s’activer.
- Le bouton de mise à jour est désactivé pendant toute lecture audio.

## Fiabilité de la publication

La version du logiciel, le catalogue des nouveautés et le changelog sont vérifiés ensemble avant le build. Le déploiement sauvegarde PostgreSQL avant d’appliquer une migration.

## Que devez-vous faire ?

Rien dans l’immédiat. Lorsqu’une prochaine version sera prête, arrêtez les lectures en cours puis utilisez le bouton **Mettre à jour**. L’application se recharge avec la nouvelle version.
