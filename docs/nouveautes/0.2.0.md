# CueForge 0.2.0

<p class="release-lede">25 août 2026 · Gestion des versions</p>

## Interface

- ajout d’une fenêtre contenant les changements de version ;
- ajout d’un indicateur pour les notes non consultées ;
- accès aux notes depuis les paramètres ;
- affichage de la version dans la barre d’état.

## Mise à jour PWA

Une nouvelle version du service worker reste en attente après son téléchargement. L’application affiche le bouton **Mettre à jour**. Ce bouton est désactivé tant qu’une lecture audio est active.

Son activation remplace le service worker courant et recharge l’application.

## Publication

Le numéro de version est vérifié dans `package.json`, le catalogue des nouveautés, le changelog et la page de documentation correspondante. Le déploiement crée une sauvegarde PostgreSQL avant les migrations.
