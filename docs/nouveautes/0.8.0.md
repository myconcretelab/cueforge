# CueForge 0.8.0

Date de publication : 25 août 2026.

## Catalogue des forfaits

La rubrique **Forfaits** du tableau de bord `/admin` affiche les informations suivantes pour chaque forfait :

- état actif ou inactif ;
- utilisation comme forfait par défaut ;
- prix mensuel et annuel ;
- quota de stockage ;
- durée d’essai ;
- nombre de comptes associés.

La partie supérieure de la rubrique affiche le nombre de forfaits configurés, le nombre de forfaits actifs, le total des comptes attribués et le nom du forfait par défaut.

## Opérations

Le bouton **Nouveau forfait** ouvre un formulaire vide. Le bouton **Dupliquer** reprend le nom, la description, les prix, le quota, la durée d’essai et l’état actif du forfait source. Le nouveau code reste à saisir.

Le bouton **Supprimer** nécessite une seconde validation. Il est désactivé pour le forfait par défaut et pour tout forfait encore attribué à un compte.

## Attribution à un compte

La fenêtre de modification d’un compte affiche le prix mensuel, le prix annuel, le quota et la durée d’essai du forfait sélectionné. Le champ de quota exceptionnel reste indépendant du forfait.
