# SonoRiva 1.11.0

Date de publication : 31 août 2026.

## Colonne gauche réorganisable

La colonne gauche devient une zone de dépôt permanente dans l’éditeur de disposition. Elle accepte les blocs **Actions de déclenchement**, **Lectures en cours** et **Playlist**.

Le bloc **Actions de déclenchement** peut être déplacé sur la grille ou permuté avec un bloc compatible de la colonne gauche. Quand un bloc quitte la grille pour rejoindre cette colonne, les blocs restants s’étendent dans l’espace horizontal libéré.

## Régie compacte

Dans le modèle **Régie compacte**, les lectures en cours et la playlist conditionnelle forment un ensemble : déplacer les lectures dans la colonne gauche y place aussi la playlist et conserve son bouton d’ouverture.

Sur un écran de 900 pixels de large ou moins, les actions restent dans le menu latéral. Les catégories, le soundboard, les lectures et la playlist sont affichés dans le flux vertical principal.
