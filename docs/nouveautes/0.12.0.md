# SonoRiva 0.12.0

Date de publication : 26 août 2026.

## Abonnement

La rubrique **Paramètres → Offre et stockage** affiche les commandes de facturation lorsqu’elles sont activées sur le serveur.

Avant la souscription :

- le forfait se sélectionne parmi les offres publiques ;
- la périodicité peut être mensuelle ou annuelle ;
- le bouton **Continuer avec Stripe** ouvre la page Checkout hébergée par Stripe.

Après la souscription, le bouton **Gérer l’abonnement et les factures** ouvre le portail Stripe associé à l’espace.

## Mise à jour de l’accès

Le retour de la page de paiement ne modifie pas directement l’espace SonoRiva. Le forfait, le quota, la période et l’état d’accès sont mis à jour après réception de la confirmation Stripe par le serveur.

Les états appliqués sont les suivants :

- essai Stripe en cours : accès d’essai jusqu’à la date indiquée ;
- abonnement actif : accès complet selon le forfait ;
- paiement en retard : accès maintenu pendant le délai de grâce ;
- abonnement terminé ou impayé : espace en lecture seule ;
- suspension administrative : espace suspendu quel que soit l’état Stripe.
