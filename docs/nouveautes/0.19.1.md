# CueForge 0.19.1

Date de publication : 29 août 2026.

## Association du Bridge

Le navigateur récupère maintenant sa clé locale lorsque CueForge Bridge accepte le ticket d’association. La clé est copiée dans la réponse avant d’être effacée du ticket sur le serveur.

La consommation et l’effacement sont exécutés dans une transaction. Le ticket reste à usage unique : une seconde demande ne renvoie aucune clé.

Les associations tentées avant cette version doivent être relancées depuis **Paramètres → Moteur et sorties audio → Connecter le bridge**. Il n’est pas nécessaire de réinstaller l’application native.
