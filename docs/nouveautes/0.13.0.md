# SonoRiva 0.13.0

Date de publication : 27 août 2026.

## Création du compte

Le formulaire d’inscription affiche les forfaits publics disposant d’un tarif Stripe. Il demande :

- le nom affiché ;
- l’adresse e-mail ;
- le mot de passe ;
- le forfait ;
- la périodicité mensuelle ou annuelle.

Le bouton **Continuer avec Stripe** crée le compte puis ouvre la page Checkout hébergée par Stripe. Stripe enregistre le moyen de paiement sans prélever le prix de l’abonnement pendant l’essai.

## Essai et première échéance

L’essai commence lorsque Stripe crée l’abonnement après la validation du Checkout. Sa durée correspond au nombre de jours défini sur le forfait. Pour un essai de 14 jours, la première échéance intervient à la fin de ces 14 jours.

L’accès SonoRiva reste en lecture seule avant la confirmation Stripe. Après cette confirmation, le webhook applique le forfait choisi, son quota et l’état d’essai.

Si l’utilisateur annule Checkout, le compte reste créé sans abonnement actif. La souscription peut être reprise après connexion depuis **Paramètres → Offre et stockage**.
