# SonoRiva 1.1.0

Date de publication : 31 août 2026.

## Tags des morceaux

Les réglages d’un morceau permettent d’ajouter et de supprimer jusqu’à 30 tags. Chaque tag contient au maximum 40 caractères. Les imports Freesound enregistrent automatiquement les tags fournis par le service.

## Recherche

La barre de recherche contient un sélecteur **Noms / Tags**. Le mode **Noms** est actif par défaut et recherche le titre du morceau, le nom du fichier ainsi que le nom des playlists. Le mode **Tags** recherche uniquement les morceaux à partir de leurs tags.

Lorsque plusieurs mots sont saisis en mode **Tags**, chacun doit correspondre à au moins un tag du morceau.
