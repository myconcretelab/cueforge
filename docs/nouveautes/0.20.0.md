# CueForge 0.20.0

Date de publication : 29 août 2026.

## Connexion rapide au Bridge

Le bloc **Sortie audio** de la barre de régie affiche maintenant une LED d’état et deux commandes compactes pour CueForge Bridge.

- rouge : le Bridge ne répond pas sur la machine ;
- orange : le Bridge est détecté mais le navigateur n’est pas associé ;
- bleu : le Bridge est associé et prêt, mais le moteur Navigateur reste actif ;
- vert : le Bridge est le moteur audio actif ;
- gris : détection en cours ou Bridge non inclus dans le forfait.

Le bouton de connexion adapte son action à l’état courant : association, ouverture de l’application native, activation du moteur Bridge ou retour au moteur Navigateur. Le bouton d’actualisation relance immédiatement la détection locale. Celle-ci est aussi effectuée automatiquement toutes les cinq secondes lorsque le compte dispose du Bridge.
