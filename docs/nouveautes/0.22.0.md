# CueForge 0.22.0

Date de publication : 29 août 2026.

## Sorties audio

Lorsque CueForge Bridge détecte plusieurs sorties physiques, le grand Play de chaque morceau est entouré par la couleur de la sortie principale. Les petits Plays représentent uniquement les autres sorties et sont alignés sur le bas du grand bouton. Le témoin de préchargement reste séparé de ces commandes.

La barre de régie affiche le nom et le code couleur de chaque sortie physique. La sortie principale est visuellement distinguée dans cette légende.

## Cache du Bridge

La fenêtre de CueForge Bridge affiche le nombre de fichiers audio présents dans son cache et leur taille totale sur le disque. La valeur est recalculée lors de l’actualisation automatique et après la suppression du cache.

## Installation macOS

Les images disque de CueForge Bridge 0.4.0 utilisent un fond bilingue français-anglais. Il représente le déplacement de l’application vers le dossier Applications et le chemin **Réglages Système → Confidentialité et sécurité → Ouvrir quand même** utilisé lorsque macOS bloque l’application non notariée.
