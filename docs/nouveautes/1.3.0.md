# SonoRiva 1.3.0

Date de publication : 31 août 2026.

## Commandes clavier

Les catégories sont parcourues avec `Tab` et `Ctrl + Tab`. Les positions `1` à `9` démarrent les neuf premiers morceaux visibles ; `Ctrl` déclenche la même position avec un fondu enchaîné. `AltGr` charge tous les morceaux de la catégorie actuelle dans le cache.

Chaque combinaison est modifiable dans **Paramètres → Raccourcis clavier** et enregistrée pour le spectacle sélectionné.

## Routage et volume maître

Avec SonoRiva Bridge et deux sorties physiques routables, `Maj` maintenue envoie les nouveaux départs vers la sortie secondaire. `Verr. Maj` bascule la sortie utilisée par les départs suivants.

Les touches `+` et `-` modifient le volume maître par pas de 2 %. Avec `Ctrl`, le pas est de 10 %. Le volume maître agit sur les lectures en cours et suivantes avec le moteur Web Audio et SonoRiva Bridge 1.0.4.
