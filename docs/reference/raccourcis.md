# Raccourcis et commandes

## Commandes globales

Les actions des trois touches d’arrêt sont configurées dans **Paramètres → Raccourcis clavier**.

| Touche | Réglage initial | Actions disponibles |
| --- | --- | --- |
| `Échap` | Arrêter avec les fondus | Avec fondus, immédiat ou aucune action |
| `Retour arrière` | Arrêter avec les fondus | Avec fondus, immédiat ou aucune action |
| `Espace` | Arrêter immédiatement | Avec fondus, immédiat ou aucune action |

Ces réglages appartiennent au spectacle sélectionné.

## Navigation, départs et volume

Les affectations suivantes sont également enregistrées pour le spectacle sélectionné. Pour modifier une affectation, cliquez sur sa combinaison dans **Paramètres → Raccourcis clavier**, puis pressez la nouvelle combinaison. Pour les commandes de morceau, pressez une touche de `1` à `9` avec les modificateurs voulus.

| Réglage initial | Commande |
| --- | --- |
| `Tab` | Passer à la catégorie suivante |
| `Ctrl + Tab` | Revenir à la catégorie précédente |
| `1` à `9` | Démarrer l’un des neuf premiers morceaux visibles |
| `Ctrl + 1` à `Ctrl + 9` | Lancer le morceau correspondant avec un fondu enchaîné |
| `AltGr` | Mettre en cache tous les morceaux de la catégorie actuelle |
| `Maj` maintenue | Envoyer les nouveaux départs vers la sortie secondaire |
| `Verr. Maj` | Basculer les prochains départs entre sorties principale et secondaire |
| `+` / `-` | Monter ou baisser le volume maître de 2 % |
| `Ctrl +` / `Ctrl -` | Monter ou baisser le volume maître de 10 % |

La navigation boucle entre **Tous les sons** et les catégories affichées. Le chargement d’une catégorie utilise le même cache que le bouton **Disponible hors ligne** du tableau de bord.

Le volume maître s’applique aux lectures en cours et suivantes. Sa valeur est enregistrée dans le navigateur et affichée dans la barre d’état.

Les commandes de sortie secondaire nécessitent le moteur SonoRiva Bridge actif, la fonction de routage par morceau et au moins deux sorties physiques. **Maj** force temporairement la sortie secondaire ; **Verr. Maj** conserve la sortie choisie jusqu’à la prochaine bascule.

## Actions de la souris

Le clic gauche et le clic droit possèdent un réglage indépendant pour chaque spectacle.

| Action | Effet |
| --- | --- |
| Démarrer | Ajoute une nouvelle lecture de la piste |
| Fondu enchaîné | Arrête toutes les lectures avec leurs fondus puis démarre la piste |
| Fondu d’entrée | Démarre la piste avec son fondu d’entrée |
| Remplacer | Arrête immédiatement toutes les lectures puis démarre la piste |
| Arrêter | Arrête les instances actives de la piste |
| Aucune action | Ignore le clic correspondant |

Les deux sélecteurs sont affichés dans la barre latérale du lecteur principal.
